# Story Vision

Расширение SillyTavern для визуализации сцен: библиотека референсов персонажей и локаций с привязкой к чатам/аркам, генерация image-промптов через Connection Profile (DeepSeek на подписке NanoGPT) и отрисовка через NanoGPT Image API (`POST /api/v1/images`, `input_references`).

## Статус: итерация 1

Реализовано:
- Библиотека референсов: загрузка (авторесайз до 1024px, JPEG), теги, алиасы, арки, заметки, приоритет.
- Каст чата: привязка «имя персонажа → референс» в `chat_metadata`, наследуется ветками чата.
- Поле «арка чата» для автоматического выбора версии персонажа.
- Логика разрешения имён: каст → библиотека (тег/алиас) → фильтр по арке → выбор из кандидатов.
- Скелет настроек: API-ключ NanoGPT, профиль промптера, глубина контекста.

Итерация 2 (следующая): промптер через ConnectionManagerRequestService, discovery моделей, генерация с референсами, попап результата и галерея сессии.

## Чек-лист тестирования (итерация 1)

1. Wand-меню → Story Vision открывает попап библиотеки.
2. «Добавить» → выбрать изображение → превью появилось → заполнить тег → Сохранить. Карточка появилась в сетке, файл лёг в `data/<user>/user/images/StoryVision/`.
3. Редактирование карточки меняет поля, замена изображения работает.
4. «В каст» → имя закрепилось, карточка видна в секции каста. Перезагрузить страницу — каст на месте (сохранился в метаданных чата).
5. Открыть другой чат — каст пуст (изоляция чатов), библиотека общая.
6. Поле «Арка чата» сохраняется после перезагрузки.
7. Удаление рефа убирает его и из каста.
8. Проверить всё то же с телефона (s24-ultra): попапы не уползают, кнопки нажимаются.
